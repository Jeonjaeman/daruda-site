## 1. MAIN (메인 페이지)

1. **Full Image** 배경
   - 여러 이미지가 **3초 간격**으로 **좌측 → 우측으로 무빙**
   - 최대 **10장**까지 업로드 가능 (관리자)
   - **각 이미지 색상에 맞춰 로고·메뉴 색상이 바뀌는 기능** 필요 (stof.kr 참고: 갈색 사진엔 하늘색 텍스트, 회색 사진엔 검정 텍스트)
2. **`DARUDA` 로고** 좌측 상단 고정. 바로 옆에 작은 폰트로 고정 텍스트 3줄
   - `company 주식회사 다루다 owner 이○○` (대표자 성함 — 이미지 해상도상 판독 불가, 확인 필요)
   - `business number 789-81-01815` (판독 추정치, 확인 필요)
   - `copyright (c) 2026 DARUDA All rights reserved.`
3. **메뉴 4개**, **페이지 하단** 배치: about / archive / press / contact (가로로 넓게 분산)
4. about · press · contact 클릭 시 **상세 페이지가 아닌 오버레이** 형식
   - 메인 위에 관련 카테고리 내용만 나오도록
   - 오버레이가 열려 있는 중에도 **배경 이미지 무빙은 계속** (about/press/contact 공통)
   - 메뉴에 마우스 오버 / 클릭 시 해당 메뉴 위에 **로고의 'U' 모양**이 표시됨 (예: about 위에 큰 U)

  > 설계 및 시공을 비롯하여 브랜딩, 제작 가구 등 공간에서 경험할 수 있는 모든 것을 고민하고 만듭니다.

## 5. archive (별도 페이지)

- 메인의 `archive` 클릭 시 이동
- 페이지 **2분할**
  - 왼쪽: 큰 아웃라인 글자 **`P`**, 위에 `( 4 )`, 아래 `PROCESSING`
  - 오른쪽: 큰 아웃라인 글자 **`A`**, 위에 `( 53 )`, 아래 `ARCHIVING`
  - 괄호 숫자 = 현재 진행 프로젝트 수 / 완료 프로젝트 수 (**관리자에서 수정**)
- 좌측 상단 `DARUDA` 로고, 우측 상단 `archive` 메뉴명
- **미색(크림) 배경**에 타이포그래피 강조

## 6. PROCESSING (상세 페이지)

- 현재 진행 중인 작업 과정을 보여주는 페이지, 이미지는 관리자에서 직접 관리
- 왼쪽 상단에 `PROCESSING` 표기
- 이미지 그리드 (기획안: 4열 × 2행)
- 이미지 클릭 시 **확대(라이트박스)**, **키보드 화살표**로 순차 이동
- 하단 **검정 박스**에 흰 글자 `THIS IS WHAT WE'RE MAKING` — **왼쪽 → 오른쪽으로 흐르는** 마퀴

## 7. ARCHIVING (상세 페이지)

- 완료된 작업물 페이지
- 행 구분: **LIVING** / **COMMERCIAL** — 각 행 4장 + `>` (가로 넘김)
- 각 이미지 하단(검정 띠)에 **타이틀 / 시공연도 / 분야** 고정 노출 (예: `ep.i` / `2026 / SPACE,BRANDING`)
- 관리자에서 이미지 교체·정보 수정
- 하단 검정 박스 마퀴 `ARCHIVE : We make and design` (왼쪽 → 오른쪽)

## 8. 프로젝트 상세 (LIVING / COMMERCIAL 항목 선택 시)

- **왼쪽 메인 이미지** + 하단 `location : / area : / use :`
- **오른쪽 서브 이미지** — 가로·세로 사진 혼합 레이아웃 (참고: stof.kr/works/flat-point-daejeon, salad-bowl.co.kr)
- 메인·서브 이미지 클릭 시 확대, 순서대로 넘김
- **메인 1장 + 서브 20장**까지 등록
- 관리자에서 **서브 이미지 레이아웃 변경** 및 사진 추가

## 10. 확인이 필요한 항목 (의뢰자 질의 리스트)

1. 대표자 성함 (로고 옆 텍스트) — 이미지 판독 불가
2. 사업자번호 `789-81-01815` 맞는지
3. "넓은 모양의 'D'" — 오버레이 사각형의 정확한 비율/모서리(사각 vs 한쪽 둥근) 의도
4. 메인 슬라이드 "좌→우 무빙" — 이미지가 옆으로 밀려 넘어가는 방식인지, 한 장이 천천히 패닝하는 방식인지 (v1은 **밀려 넘어감 + 미세 패닝** 조합으로 구현)
5. about/press/contact "마우스 오버 **또는** 클릭" — 오버 즉시 열림이면 모바일 대응 방식 (v1: 데스크톱 오버로 열림, 클릭으로 고정, 모바일은 탭)
6. 로고·메뉴 색상 변경 — 자동(밝기 감지) vs 관리자에서 이미지별 색 지정 (v1: 자동 + 관리자 지정 가능 구조)
7. ARCHIVING 카운트(53)가 실제 프로젝트 수와 자동 연동되길 원하는지, 수기 입력인지
8. 관리자 로그인 방식 / 호스팅 환경 (추후 견적·구조 결정에 필요)
9. PRESS 매거진 실제 자료(커버·지면 스캔) 제공 여부
10. 실제 프로젝트 사진 및 LIVING/COMMERCIAL 분류 자료 제공 시점
